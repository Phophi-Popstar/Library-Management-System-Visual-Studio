# 📚 Library Management System

A web-based library management system for tracking books and readers with a clean, modern UI.

## Features

✨ **Book Management**
- Add new books with reader name, title, and genre
- Categorize books by Fiction, Programming, or Art
- Real-time book counter

📖 **Issue & Return System**
- Issue books to readers
- Return issued books
- Track book status at a glance

🔍 **Search & Filter**
- Search books by reader name, title, or genre
- Live search results

🗑️ **Delete Books**
- Remove books from the library

## Technologies Used

- **HTML5** - Structure
- **CSS3** - Modern styling with flexbox
- **JavaScript** - Dynamic functionality
- **Font Awesome** - Icons

## How to Use

1. Open `index.html` in your browser
2. Fill in the Reader name, Book title, and Genre
3. Click "Add Book" to add to library
4. Use "Issue" to issue a book, "Return" to return it
5. Use "Delete" to remove books
6. Search for books using the search bar
